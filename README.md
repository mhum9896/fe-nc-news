This is the frontend project for a news wesbite.
The website allows the user to show comments for each article and add votes to them.

The backend for this project can be found here: https://github.com/mhum9896/be-nc-news

To run the project locally:
1) Fork and clone the repo
2) Install dependencies using 'npm i'
3) Run the project locally using 'npm run dev'

Node.js v23.7.0 was used for this project
